# beam

beam is a command-line file transfer utility for local network.

![beam](https://github.com/user-attachments/assets/3ab77899-0b36-48af-a6fe-92abdc881730)

## Installation

with Go:

```bash
go install github.com/mati-33/beam@latest
```

## Usage

send a file:

```bash
beam emit <file name>
```

receive a file:

```bash
beam absorb <beam code>
```
